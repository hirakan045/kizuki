# タスクリスト — レポート内容のプロンプト調整（WBS 5.3.7）

## 背景

実機で生成されたレポートを読んだ結果、以下2点が「読んで良かった」と感じられない要因として指摘された。

1. 睡眠データが無い日に、その不在をただ説明する文章（「〜のため比較はできなかった」）が価値を感じない
2. 「データが少なくて判断できない」という趣旨の文言が、ユーザーのテンションを下げる

対応方針：**「無いことを説明しない。ある情報だけを書く」という原則をシステムプロンプト全体に一貫させる。**

- [x] `src/storage/dayRecord.ts` に `clearDay(dateKey)` を実装
- [x] `api/report.ts` のSYSTEM_PROMPTを修正
  - [x] 「〜できなかった」「判断できない」「比較できない」という趣旨の文を書かない、という制約を追加（婉曲な言い回しも禁止するよう2段階で強化）
  - [x] 睡眠段落を条件付きにする（対象日に睡眠データが無ければ、①昨夜の睡眠段落・②歩数との関係段落の両方で睡眠に触れない）
