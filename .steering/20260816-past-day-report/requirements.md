# 要求 — 過去日のレポート生成（WBS 5.3.8, 5.3.9）

## 背景

WBS 5.3.3（`.steering/20260815-report-trigger/`）で、今日タブ（`app/(tabs)/index.tsx`）の生成トリガーを実装し、実機で幸福度入力→レポート生成まで確認済み。ただしそのrequirements.mdでは「日別詳細画面（`app/day/[date].tsx`）での生成トリガー」を明示的に対象外としていた。

利用者から、過去日（幸福度・睡眠時間は記録済みだがレポートが無い日）についてもレポートを生成したいという要望があった。

### 技術的な前提

`DayRecord.steps` / `sleepMinutes`（`src/types/index.ts`）は現状「レポート生成時点の値」としてのみ保存される設計。そのため、レポートを一度も生成していない日は、幸福度があっても歩数・睡眠データがストレージに存在しない。

`fetchStepsCount(date)` / `fetchSleepMinutes(date)`（`src/lib/healthkit.ts`）はどちらも任意の`Date`を受け取れるため、対象日を指定してHealthKitから取得し直すこと自体は可能（ただしHealthKit側にその日のデータが残っている場合に限る）。

## やりたいこと

利用者と相談し、以下の方針で合意した。

1. **起動時に直近30日分の歩数・睡眠を同期して保存する**（今日タブの`load()`内）。`DayRecord.steps` / `sleepMinutes`を「レポート生成時点のみ保存」から「未生成の日は毎起動で同期」に変更する
2. **日別詳細画面（`app/day/[date].tsx`）に生成トリガーを追加する**
   - 幸福度をその場で入力したとき（今日タブと同様、入力直後に生成）
   - 画面を開いたとき、対象日の幸福度が入力済み・レポートが未生成なら自動生成する（この機能実装前に幸福度だけ記録されていた日の救済も兼ねる）

これによりPRD F-3に新規要件を追加する（`docs/product-requirements.md`更新が必要、設計時に反映）。

## 決定事項（今回相談して決めたこと）

- 対象は**直近30日以内**の過去日に限る。`buildReportRequest`の`history`は対象日から遡って30日分を組み立てる設計であり、それより古い日は同期対象外（HealthKit側にデータが残っていても、このタスクでは扱わない）
- 歩数・睡眠の同期は**レポートが未生成の日のみ**行う。レポート生成済みの日の`steps`/`sleepMinutes`は上書きしない（`DayRecord`型コメントの「表示値とレポート本文の食い違いを防ぐ」という既存の意図を壊さないため）
- 日別詳細画面の生成トリガーは、5.3.3で作った`generateAndSaveReport`・`buildReportRequest`を対象日ベースに一般化して再利用する（今日タブ専用の実装から共通化する）
- 同時に複数の過去日を自動生成することはしない（利用者が開いた画面の対象日1件のみ）。起動時に全過去日を一括生成するバックフィルは行わない

## 受け入れ条件

- [ ] アプリ起動時、レポート未生成の直近30日以内の各日について、歩数・睡眠がHealthKitから同期され`DayRecord`に保存される
- [ ] レポート生成済みの日の`steps`/`sleepMinutes`は起動時の同期で上書きされない
- [ ] 日別詳細画面で、対象日の幸福度未入力の状態から入力すると、レポート生成APIが呼ばれ結果が表示される
- [ ] 日別詳細画面を開いたとき、対象日が「幸福度入力済み・レポート未生成」なら自動でレポート生成が始まり、完了後に表示される
- [ ] 生成中は`GeneratingIndicator`（今日タブと同じコンポーネント）を表示する
- [ ] 同一マウント中に同じ対象日への二重生成が起きない
- [ ] 対象日が31日以上前の場合、自動生成は行わない（歩数・睡眠が同期されておらず`null`のまま生成すると精度の低いレポートになるため）
- [ ] 型チェック・Lintが通る
- [ ] 実機で、過去日（幸福度のみ記録済みの日）を開いてレポートが生成されることを確認する

## 対象外（今回やらないこと）

- 起動時の全過去日一括バックフィル生成（今回は画面を開いた1件のみ）
- 31日以上前の日のレポート生成
- エラー表示・リトライUI（WBS 5.3.5と同様、握りつぶして次回に委ねる）
- 折れ線グラフ（WBS 4.3.3、別スコープ）
