# ユビキタス言語定義 — きづき

作成日: 2026-08-08

用語の揺れを防ぐため、**ドキュメント・コード・UI文言のすべてでこの定義に従う。**

---

## 1. ドメイン用語

| 日本語       | 英語（コード上） | 定義                                                       |
| ------------ | ---------------- | ---------------------------------------------------------- |
| きづき       | Kizuki           | 本プロダクトの名称。UI表示は常にひらがな                   |
| 幸福度       | happiness        | ユーザーが1日を振り返って入力する5段階の主観評価           |
| 歩数         | steps            | HealthKit から取得する、その日の歩数の合計                 |
| 睡眠時間     | sleepMinutes     | HealthKit から取得する睡眠時間（**分単位**）               |
| レポート     | report           | AIが生成する、その日の振り返り本文                         |
| 発見         | discovery        | レポートに1件含まれる、データから導いた気づき              |
| 就寝予定時刻 | bedtime          | ユーザーが設定する就寝予定の時刻。当日入力の解禁判定に使う |
| 日次レコード | DayRecord        | 特定の日付に紐づく全データのまとまり                       |

### 「発見」の種類

| ID  | 日本語           | 英語                   |
| --- | ---------------- | ---------------------- |
| D-1 | 過去最高         | `personalBest`         |
| D-2 | 平均との差       | `deviationFromAverage` |
| D-3 | 連動             | `correlation`          |
| D-4 | 曜日の傾向       | `weekdayPattern`       |
| D-5 | 週次の変化       | `weeklyChange`         |
| D-6 | データ蓄積の予告 | `dataAccumulation`     |

## 2. 使用を禁止する用語

プロダクトの設計原則に反するため、**コード上の識別子としても使わない。**

| 禁止語                | 理由                         | 代替                         |
| --------------------- | ---------------------------- | ---------------------------- |
| 目標 / goal / target  | 目標設定は実装しない         | （概念そのものが存在しない） |
| 達成 / achievement    | 評価・採点を行わない         | —                            |
| ストリーク / streak   | 連続記録は実装しない         | —                            |
| 推奨 / recommend      | 促す表現を使わない           | `discovery`（発見）          |
| アドバイス / advice   | 医療アドバイスと見なされうる | `report`（レポート）         |
| スコア / score        | 採点しない                   | —                            |
| 改善提案 / suggestion | 促す表現                     | `discovery`                  |

⚠️ **`recommendation` や `advice` という変数名を使うと、実装の発想がそちらに引きずられる。**用語の禁止は設計原則の防波堤である。

## 3. 技術用語

| 用語                 | 定義                                                                     |
| -------------------- | ------------------------------------------------------------------------ |
| 統計クエリ           | `queryStatisticsForQuantity`。HealthKit 側で重複排除して集計する方式     |
| サンプルクエリ       | `queryQuantitySamples`。個別の記録を取得する方式。歩数の合計には使わない |
| development build    | EAS で作成する開発用ビルド。ネイティブモジュールを含む                   |
| ステアリングファイル | `.steering/` 配下に置く作業単位のドキュメント                            |

## 4. UI文言の表記ルール

| 対象                   | 表記                                                          |
| ---------------------- | ------------------------------------------------------------- |
| アプリ名               | きづき（ひらがな）                                            |
| 幸福度の質問（当日）   | 今日はどんな一日でしたか                                      |
| 幸福度の質問（前日）   | 昨日はどんな一日でしたか                                      |
| 幸福度の質問（過去日） | ◯月◯日はどんな一日でしたか                                    |
| 朝の通知               | 昨日はどんな一日でしたか。1タップで今朝のレポートが届きます。 |

### 数値の表記

| 対象     | 表記                                   | 例        |
| -------- | -------------------------------------- | --------- |
| 歩数     | 3桁区切り + 「歩」                     | 8,432歩   |
| 睡眠時間 | 時間と分                               | 6時間52分 |
| 幸福度   | **数値を表示しない。**言葉と絵文字のみ | —         |

⚠️ 幸福度を「4/5」のように表示しない。**採点の印象を与えるため。**

## 5. コード上の命名規則

### 日付

| 用途             | 型・形式                               |
| ---------------- | -------------------------------------- |
| ストレージのキー | `day:YYYY-MM-DD`                       |
| 日付文字列       | `YYYY-MM-DD`（端末のローカル時刻基準） |
| 日時             | ISO 8601（`generatedAt` など）         |

### 命名

| 対象                       | 規則             | 例                            |
| -------------------------- | ---------------- | ----------------------------- |
| 変数・関数                 | camelCase        | `fetchSteps`, `sleepMinutes`  |
| 型・コンポーネント         | PascalCase       | `DayRecord`, `HappinessInput` |
| 定数                       | UPPER_SNAKE_CASE | `DEFAULT_BEDTIME`             |
| ファイル（コンポーネント） | PascalCase       | `ReportView.tsx`              |
| ファイル（その他）         | camelCase        | `storage.ts`, `discovery.ts`  |

### 単位を名前に含める

⚠️ 時間・期間を扱う変数は、**単位を名前に含めること。**

| ✅ 良い        | ❌ 悪い                       |
| -------------- | ----------------------------- |
| `sleepMinutes` | `sleep`                       |
| `bedtimeHour`  | `bedtime`（時刻か時間か不明） |
